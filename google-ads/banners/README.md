# באנרים לרימרקטינג
נבנו מתמונות, לוגו ופונט (Fb Monopoly) שבדפי הנחיתה ב־zamarotnadlan.co.il.

- `gif/`: באנרים מונפשים, 4 פריימים × 2.5 שניות, 3 הופעות (30 שניות). כולם עד 150KB, כדרישת גוגל. לכל גודל יש גם `_static.png` (פריים המחיר).
  גדלים: 300×250, 336×280, 300×600, 728×90, 320×100, 320×50. פרויקטים: hadera, rehovot.
- `responsive/`: תמונות נקיות למודעות רספונסיביות (1.91:1, 1:1, 4:5) ולוגו ריבועי בשתי גרסאות.
- `*_preview.png`: כל הפריימים בעמוד אחד, לאישור.
- `banner.html` + `render.js` + `gif.py` + `crops.py`: הקוד שמייצר את הבאנרים. מניחים ש־`img/` ו־`font_FbMonopolyVF.woff2` נמצאים לידם (מורידים מהאתר).
