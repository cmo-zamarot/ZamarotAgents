# אפיון: עמוד כללי "השקעות בקרקע" (צמרות)
מבוסס על סריקת עמודי הבית של מקרו נדל"ן, דרך הקרקע, קב (HLK), ארבל, המרכז הארצי לקרקעות, קליימקס, אקו קפיטל, אשחר, קוסמוס, מעין ליבנה (2026-11-15).
התוכן המלא, כפי שנשלח למשתמש, נמצא בהודעה שבשיחה. זה תקציר העקרונות.

- מטרות: יעד לקמפיין הכללי, לקמפיין המתחרים ולרימרקטינג הכללי. לעבור את מדיניות גוגל ולהתאים למילים "השקעה בקרקע" ו"קרקע להשקעה".
- מבנה: Hero עם טופס ← פס אמון ← מה זו השקעה בקרקע ← רקורד מתועד ← פרויקטים בשיווק ← תהליך ← למה יזם ולא משווק ← המלצות ← מה לבדוק לפני (צ'קליסט) ← שאלות ותשובות ← אודות ופרטי חברה ← טופס סגירה והסתייגות.
- בידול מול המתחרים: רקורד מתועד, שקיפות עמלות, יזם ולא משווק, D&B.
- אסור: אחוזי תשואה, "פי X", שמות מתחרים, "אושרה" בלי מקור.
